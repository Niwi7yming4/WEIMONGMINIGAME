# 舉手投足我就是騙 — R5 Quickplay

此目錄是 GitHub Pages 快速測試版。目標是「點網址 → PLAY NOW → 直接開始」，不要求下載 ZIP 或安裝 Python。

- 第一個 scripted encounter：18 秒。
- 18 分鐘局：14 段 scripted encounter，加上 5/10 分鐘精英、15 分鐘 Boss、18 分鐘通關。
- 開局 32 FLOW、8/24 XP，讓第一次升級與流派爆發更快成形。
- 高 FLOW / 高連殺 / encounter 期間會持續出現 arena pulse、speed cut、radial spokes。
- 靜態版缺少聊天附件中的 GLB 二進位，因此直接用內建 humanoid bone fallback avatar；玩法、武器、BUILD、VFX、音效與 Director 仍使用同一份 R5 game.js。
- 完整 ZIP 仍包含原始兩個 GLB，並優先走 GLB + locomotion retarget。
